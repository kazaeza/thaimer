# Протокол BLE термометра BFOUR BF-40

Восстановлен из официального приложения **BFOUR** (`com.hay.bfour`, версия 1.1.1, Flutter).
Логика протокола находится в `package:bf_home/device/grill.dart` и `ble_device.dart`.
Протокол общий для BF-5, BF-6, BF-20, BF-30, BF-40 и BF-60, отличается только число щупов.

## GATT

| Что | UUID |
|---|---|
| Сервис | `0000FFB0-0000-1000-8000-00805F9B34FB` |
| Запись (app → термометр), write with response | `0000FFB1-...` |
| Уведомления (термометр → app) | `0000FFB2-...` |

Рукопожатия, авторизации и запроса MTU нет: все пакеты не длиннее 20 байт.

## Реклама (сканирование)

Официальное приложение сканирует с фильтром по сервису `FFB0` (и `FFA0` для гигрометров BF-7/BF-8/BF-11).
Модель определяется по Manufacturer Specific Data. Ниже байты считаются от начала payload, без 2 байт Company ID:

| Байт | Значение |
|---|---|
| 0 | тип устройства: `1` BF-20, `3` **BF-40**, `4` BF-30, `5` BF-60, `0xFF` BF-5 |
| 1..6 | MAC-адрес |

Число щупов: BF-30 — 1; BF-20, BF-40, BF-60 — 2; остальные — 6.

## Формат пакетов

Каждый пакет в обе стороны начинается с `0x55`, второй байт — код команды.
На каждую команду термометр отвечает уведомлением с тем же кодом.

### Термометр → приложение

| Пакет | Смысл |
|---|---|
| `55 00 T1h T1l T2h T2l …` | Температуры щупов, примерно раз в секунду |
| `55 01 …` | Подтверждение «единицы дисплея» |
| `55 02 …` | Подтверждение «цели щупа» |
| `55 04 …` | Дата (приложение только логирует) |
| `55 07 01 …` | На термометре нажали кнопку: сигнал сброшен |
| `55 07 02 MM …` | Маска щупов, у которых взведён сигнал (бит 0 — щуп 1) |
| `55 0F …` | Подтверждение «интервала сигнала» |

**Температура:** `raw = (hi << 8) | lo`, big-endian, в **десятых долях °C**, независимо от единиц на дисплее.

- `FF FF` — щупа нет (не подключён, в зарядке или вне зоны).
- Если у `hi` выставлен бит 7, официальное приложение считает температуру равной 0.
- Если уведомлений нет 3 секунды, приложение считает, что щупов нет.

### Приложение → термометр

| Команда | Пакет | Примечание |
|---|---|---|
| Единицы дисплея | `55 01 UU 00` | `UU`: `1` = °C, `2` = °F |
| Цель щупа | `55 02 PP Mh Ml Nh Nl 00` | `PP` — номер щупа (1..2), `M` — верхняя граница, `N` — нижняя граница (для одной цели равна `M`). Целые градусы **в текущих единицах дисплея**. `0` выключает цель |
| Остановить сигнал | `55 07 07 00` | `07` — маска «все щупы» |
| Интервал сигнала | `55 0F II 00` | По умолчанию `5` |

## Последовательность после подключения

1. Найти сервисы и включить уведомления на `FFB2` (дескриптор CCCD `0x2902`).
2. Отправить `55 01 UU 00` (единицы дисплея).
3. Через 0,5 с отправить цели: `55 02 …` для каждого щупа по очереди, дожидаясь ответа `55 02`.
4. Через 0,5 с отправить `55 0F 05 00` (интервал сигнала).

Дальше термометр сам присылает `55 00 …` с температурами.
