# BFOUR Термо

Простое Android-приложение для беспроводного термометра **BFOUR BF-40**: альтернатива официальному приложению BFOUR.

Один экран, две большие карточки щупов (чёрный и белый). Нет регистрации, рекламы и облака.

## Что умеет

- Сам находит термометр и подключается к нему, а при обрыве связи переподключается.
- Крупно показывает текущую температуру каждого щупа.
- Цель задаётся тапом по карточке: готовые варианты (говядина rare…well done, свинина, птица, рыба, брискет) или своя температура.
- Показывает прогресс, примерное время до готовности и график за последний час.
- Предупреждает «Почти готово» за 5° до цели.
- Когда цель достигнута, включает громкий сигнал с вибрацией. Он звучит даже в беззвучном режиме, пока не нажмёте «Остановить» в телефоне или кнопку на термометре.
- Работает в фоне с выключенным экраном: в шторке висит уведомление с температурами.
- Сообщает, если связь пропала, когда что-то готовится.
- Переключает °C/°F, и единицы меняются на экране самого термометра тоже.

## Установка

1. Скачайте `BFOUR-Termo.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника.
3. Запустите приложение, разрешите Bluetooth и уведомления, включите термометр.

Нужен Android 8.0 или новее. На Android 11 и старше для поиска Bluetooth-устройств должна быть включена геолокация: таково требование системы.

## Сборка

```
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`. Он подписан отладочным ключом сборочной машины. Если собрать на другом компьютере, перед установкой старую версию придётся удалить.

Тесты протокола и логики сигнала: `./gradlew testDebugUnitTest`.

## Как устроено

| Файл | Что делает |
|---|---|
| `ble/BfourProtocol.kt` | Формат пакетов термометра (см. [PROTOCOL.md](PROTOCOL.md)) |
| `ble/BfourConnection.kt` | Сканирование, GATT, очередь записи, переподключение |
| `core/Thermo.kt` | Состояние приложения, цели, когда звонить |
| `alarm/AlarmRules.kt` | Правила «почти готово / готово / снова взвести» |
| `service/ThermoService.kt` | Фоновый сервис: держит связь, звук и уведомления |
| `ui/` | Экраны на Jetpack Compose |

Протокол восстановлен из официального приложения BFOUR 1.1.1 (`com.hay.bfour`). Описание в [PROTOCOL.md](PROTOCOL.md).
